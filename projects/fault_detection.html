Background

The question

A transmission line trips. The control room needs to know two things quickly: that something has happened, and which element it was. Protection relays report the trip directly, but relay telemetry can be lost, delayed, or ambiguous during a disturbance. So a reasonable question is whether the same conclusion can be reached from bus voltage measurements alone — the kind of data a state estimator or a fleet of PMUs already has.

The literature on this is enthusiastic. Survey papers report accuracies in the high nineties routinely. This project reproduces that result, and then asks whether it survives contact with a real instrument.

Dataset

2,800 power flow scenarios

The data is synthetic, generated on the IEEE 39-bus New England network as shipped with pandapower. Half the samples are healthy, half have one of 35 lines out of service, and every sample has its loads randomised by ±10 percent so the classifier cannot simply memorise a single operating point.

The interesting part

The leakage problem, kept visible on purpose

The first version of this scored almost perfectly and taught me nothing.

I had included line power flows in the feature vector. A line that is out of service reports no flow. So one feature in the vector was a zero sitting exactly where the answer was, and the classifier learned to read the label rather than the physics. This is target leakage, and it is the single most common way a machine learning result on power system data turns out to be worthless.

Rather than quietly fix it, the notebook keeps both feature sets so the size of the effect is measurable:

  • Set A, 78 features. Bus voltage magnitudes and angles only. The honest problem. Every headline number on this page uses Set A.
  • Set B, 113 features. Set A plus line power flows. Leaky, kept as a control.
Why keep the broken version: a portfolio that only shows working code proves you can write code that works on the problems you chose. Keeping the leaky feature set alongside the honest one shows the diagnosis, which is the harder and more transferable skill.

Here leakage matters enormously: 0.986 against 0.886. Working out what changed is where the shortcut pays off, because the zeroed flow feature points straight at the specific line. That asymmetry — leakage worthless for detection, decisive for location — was not something I expected to find and is the second most useful thing this project produced.

The negative result

What happens when you add measurement noise

All of the above is on clean simulated data, where a bus voltage is known to fifteen significant figures. Real instrument transformers and PMUs are not that good. So the last experiment adds Gaussian noise to the measurements and re-runs everything.

Key finding, and it is negative

Every model collapses to chance at 0.5 percent measurement noise. At 0.1 percent the SVM still holds at 0.957. At 0.5 percent it is at 0.538, which for a balanced two-class problem is a coin flip. Location degrades in the same way, from 0.886 to 0.117 — worse than the 2.9 percent of random guessing would suggest is possible only because the classifier is confidently wrong rather than uncertain.

The reason is physical, not statistical. Removing one line from a well-meshed network at moderate loading barely moves the bus voltages; the remaining paths pick up the flow. The signature the classifier keys on is smaller than realistic instrument error.

The honest conclusion: 0.962 on clean simulated data says almost nothing about whether this would work on a real system. That is the most useful thing this project taught me, and it is the reason the noise study exists at all.

This does not mean the approach is dead. It means the published accuracies need a noise column before they mean anything, and that a workable version would need either a much larger disturbance (a fault rather than a clean trip), time-series data rather than snapshots, or measurement redundancy from many more PMUs than this study assumes.

Honesty

Limitations

  • Synthetic data, one network, one topology. Nothing here has met a real measurement.
  • Line outages only. No short circuits, no generator trips, no transformer outages — and a genuine fault produces a far larger signature than a clean disconnection, so this is the hardest version of the problem.
  • Load variation is spatially independent, which real load is not. Real demand is correlated across a region, which would make the healthy class more structured and possibly easier to separate.
  • Snapshots rather than time series. Most of the practical signal in outage detection is in the transient, which a steady-state power flow discards entirely.
  • Gaussian noise is a crude model of instrument error. Real error has bias, quantisation and correlated components.
